# TTU Formatting Requirements Matrix

Source: Texas Tech University Graduate School, *Thesis-Dissertation Formatting Guidelines*, Revised February 2026 (35 pp.). Extracted 2026-08-22 with page citations; every row cites the page actually read. "manual silent" = no statement exists in the manual.

Columns: **#** | **Topic** | **Requirement** | **Manual page** | **Mandatory/Choice** | **Implementation** | **Status**

The Implementation and Status columns describe this template; the requirement rows are verbatim-faithful to the manual and must not be edited without re-reading it.

**Status values.** `PASS` = implemented and validated, with the validation named in the Implementation cell. `DOC` = the manual places the duty on the author; the template documents it and cannot enforce it. `n/a` = not applicable to a LaTeX template. `GAP` = required and not met.

**Validation sources referenced below.** `veraPDF` = `build\verapdf-report.xml`, PDF/UA-2 profile, `isCompliant="true"`, 1727 rules passed / 0 failed, for both layout variants. `dump` = `build\structure-dump.txt`, regenerated by `check-compliance-Windows.bat` on every run rather than kept as a snapshot, so it cannot drift from the shipped PDF. `bbox` = `pdftotext -bbox` coordinates. `render` = `pdftocairo -png` page images inspected. `log` = `build\thesis-build.log`, clean but for the documented biblatex footnote warning. Line numbers are `ttuthesis2026.cls` unless another file is named.
